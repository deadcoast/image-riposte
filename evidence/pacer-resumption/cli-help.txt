
  RIPOSTE / IMAGE SECURITY
  Clean masters in. Reviewed publishing images out. No watermark or upload gate.

  Usage: riposte [OPTIONS] COMMAND [ARGS]...
PARAMETERS                                                                                          
+--------------------------------+-----------------------------------------------------------------+
| -w, --root PATH                | Initial workspace for the interactive terminal.                 |
| --json                         | One JSON result on stdout; code-only errors on stderr.          |
| --human                        | Rich readable direct-command output, even when piped.           |
| --plain                        | Linear menus and plain ASCII output; no ANSI or motion.         |
| --no-color                     | Disable colour; also respects NO_COLOR.                         |
| --no-animation, --no-anim      | Freeze aesthetic motion; keep actual status updates.            |
| --theme [goks|dark|light|mono] | Terminal palette.  [default: goks]                              |
| --fps INTEGER RANGE            | Maximum terminal refresh frequency, not processing speed.       |
|                                | [default: 12; 4<=x<=30]                                         |
| --events                       | Code-defined progress JSON Lines on stderr for direct commands. |
| --version                      | Show installed release.                                         |
| --install-completion           | Install completion for the current shell.                       |
| --show-completion              | Show completion for the current shell, to copy it or customize  |
|                                | the installation.                                               |
| --help                         | Show this message and exit.                                     |
+--------------------------------+-----------------------------------------------------------------+
INTERFACE                                                                               
 ui                Open the interactive Rich ASCII terminal.                            
 serve             Run the existing local browser interface as an optional alternative. 
WORKFLOWS                                                                                     
 sort              Read-only recursive plan; --apply explicitly replaces sources.             
 undo-sort         Preview undo; --apply restores original names, bytes and modified times.   
 duplicates        Find DUPLICATE, MAYBE DUPLICATE and CLOSELY RELATED files.                 
 sort-riposte      Protect a selected batch at each final size; clean masters stay unchanged. 
 riposte           Protect a selected batch at each final size; clean masters stay unchanged. 
CLEAN COLLECTION                                                                   
 organize          Read-only recursive plan; --apply explicitly replaces sources.  
 categories        Discover filename categories and review explicit groups.        
 category-rules    Inspect saved rules or preview a replacement.                   
 audit             Verify clean image containers and calendar/size organization.   
 list              List and target cleaned image; never sort by file extension.    
 inspect           Independently audit a selected clean image and show its record. 
PROTECT + PUBLISH                                                                             
 publish           Protect a selected batch at each final size; clean masters stay unchanged. 
 protect           Alias of publish; same full parameter surface.                             
 publications      List batches or inspect their real output/review states.                   
 resume            Resume unfinished output work with matching local model identities.        
 review            Accept exact pixels or revoke approval.                                    
 package           Write a calendar/size ZIP containing only exact approved PNGs.             
 image             Inspect or open verified pixels without starting the browser workshop.     
LOCAL RUNTIME                                                                         
 doctor            Inspect local runtime or execute a selected local encoder probe.   
 upgrade           Explicit legacy-state rename; image and identifiers are preserved. 
OPTIONAL WORKSHOP                                                                               
 guard              Expert standalone candidate path.                                           
 compare            Sanitize and compare an externally processed candidate.                     
 qualify            Controlled encoder comparison; not an efficacy verdict.                     
 challenge          Generate clean/candidate/three-control arms with matched seeds.             
 benchmark          Legacy paired generation compatibility path.                                
 experiment         List attempts or inspect a protocol, bound outputs and recorded reviews.    
 cohort-challenge   Commit the full cohort, then generate one attempt per selected artwork.     
 cohort             List committed cohorts or inspect all members and missing-outcome bounds.   
 panel-create       Freeze calibration items, rubric and separate reviewer assignments.         
 panel              List panels or inspect exact agreement, missing decisions and disagreement. 
 panel-packet       Export the local blinded packet for one assigned reviewer slot.             
 panel-review       Record one final response.                                                  
 experiment-packet  Export verified frames with concealed arm labels and a ratings template.    
 experiment-review  Append endpoint decisions and a descriptive matched-control contrast.       
 export             Unreviewed expert trial export.                                             
 trials             List trials or read one complete trial report.                              
 evaluations        Read saved controlled encoder results.                                      
 generations        Read saved generation-run summaries.                                        
 generation         Read one complete saved generation report, including committed frame names. 
 frame              Inspect or open an exact saved generation frame; no generator runs.         
 workshop           Open helper menus, or hand off BATCH_ID ITEM_ID as exact pixels.            

  No command opens the animated terminal. Piped direct results are JSON. ROOT is a dedicated image 
folder.
