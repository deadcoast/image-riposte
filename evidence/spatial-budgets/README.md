# PAC-043 — artist-directed spatial budgets

The optional artist mask is an immutable source-bound grayscale map. Integer
channel caps are the automatic cap multiplied by conservative overlap-min mask
weights, floored at the final raster. The optimizer and independent quality
checks enforce the same bounds. Plans expose exact cap PNGs and artwork overlays;
requests/tasks/reports retain mask identity through resume, review and packaging.
Masks never enter public images or ZIPs. General saved recipes exclude them.

CLI/terminal support one PNG or a private browser-exported mask map. The terminal
opens numbered previews through its existing viewer and binds Start to the shown
mask revision. Combined sorting binds mask content before replacement. Browser
uploads, removals, explicit export, retries, cancel and stale suppression are
inside the existing optional publishing disclosure. No-mask paths keep defaults. Plans page three raster previews at a time in the
CLI, terminal and browser; all selected tasks remain in the batch. Batch start
skips preview rendering.

## Qualification limits

Existing Windows environments, synthetic images and differentiable CPU encoders
qualify mask plumbing, numerical caps, consent/binding and retained output bytes.
They do not establish pretrained-model efficacy, independent human visual approval,
screen-reader acceptance, a clean installation or the user's specific terminal
hosts. PAC-034 remains shelved. No files were committed or published by this stage.
