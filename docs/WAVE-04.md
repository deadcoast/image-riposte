## Completed development

RIPOSTE now has one Typer command entry and a real Rich interactive terminal over its working product functions. The previous argparse module is preserved as historical source, not maintained as a competing parser. The existing browser remains optional. The main seven-action deck prioritizes clean collection and protect/publish/review/package; expert comparisons stay in the secondary workshop.

The wave delivers 27 command names, searchable selection, validated fields, session-only model setup, direct-command inspection, native and linear input, three palettes, pauseable original ASCII animation, real-stage activity, ASCII artwork inspection and local exact-PNG viewing. Publishing sizes, budgets, selection IDs, repeatable models, resume, approvals, revocations, packs and all prior expert operations are callable without opening a browser. Saved generation reports and exact frames also have direct targets.

Startup scripts enter the terminal by default. Browser, light/mono, no-animation and linear alternatives are explicit. The Windows `riposte.cmd` wrapper forwards to the project-local installation, avoiding a required global PATH change. Starting or selecting a workspace remains read-only.

## Repairs made during this implementation

The first integration pass exposed and corrected global `--root` conversion for explicit `ui`, command-lens path-type parity, small-screen settings pagination, destructive-warning placement, result End-key bounds, original-master view options being silently ignored, and inherited paired-benchmark dispatch not accepting a progress parameter. The operation lifecycle now also joins its worker when terminal output fails, and handled SIGTERM restores the terminal instead of abruptly leaving raw input behind.

The effect boundary stays authoritative: an animation tick cannot commit a file. A failed model load cannot turn into noise. UI acceptance cannot skip the actual backend acknowledgements. A too-small screen cannot activate an invisible destructive prompt.
